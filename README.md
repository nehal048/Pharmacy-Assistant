# Pharmacy Assistant

A machine learning-based application for pharmacy inventory monitoring, medicine composition matching, and demand forecasting, built using Python and Gradio.

## Features
- **Inventory Overview:** View stock summaries and low-stock alerts.
- **Medicine Search:** Search medicines and view catalogue details.
- **Composition Matching:** Find medicines with matching recorded ingredients and strengths.
- **Demand Forecasting:** Explore predictions generated from historical sales data.

## Technologies
Python, Pandas, Matplotlib, Scikit-learn, Gradio, Google Colab.

## Datasets
- Historical pharmacy transaction data.
- Indian medicine catalogue data.

## Limitations
Inventory values are simulated. Forecasts use historical 2015 sales data and are experimental. Composition matches do not guarantee clinical interchangeability and require pharmacist verification.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Run the Gradio application cell to open the interface.

This is an academic machine learning project and is not connected to a live pharmacy system.
